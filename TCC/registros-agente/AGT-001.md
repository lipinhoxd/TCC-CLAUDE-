## 10. Relatório do agente

**Resumo.** Foi criada a fundação técnica: front-end Vite + TypeScript, servidor Node.js mínimo
com rota de saúde, ESLint, verificação de tipos, Vitest, variáveis de ambiente com arquivo de
exemplo e README com a execução local. Nenhuma funcionalidade de negócio foi implementada.

**Decisões técnicas (baixo impacto, tomadas pelo agente).**
1. Vite + TypeScript no front, sem framework de componentes: a fundação não precisa de um, e a
   escolha de biblioteca de interface pode ser feita na AGT-004 se necessário.
2. Servidor com `node:http` e TypeScript executado direto pelo Node (sem etapa de build do
   servidor): menos dependências. O servidor existe porque persistência e autenticação
   (AGT-002 e AGT-003) precisarão de um processo de back-end; só há a rota `/api/health`.
3. Vitest em ambiente Node, sem jsdom: os testes atuais não manipulam DOM.
4. Versões exatas fixadas (`save-exact`) para reprodutibilidade.
5. Variáveis: `HOST`/`PORT` para a API (validadas) e `VITE_APP_NAME` para o front; `.env.local`
   não versionado.
6. `erasableSyntaxOnly` e imports com extensão `.ts`, exigidos para o Node executar TypeScript.

**Limitações e pendências.** Persistência, autenticação, framework de UI e política de segurança
HTTP (cabeçalhos, CORS) ficam para as atividades seguintes. Vulnerabilidades moderadas
em ferramentas de desenvolvimento (Seção 9). Sem verificação visual no navegador.

**Pontos para revisão humana.** (a) Aceitar ou não a escolha Vite + servidor `node:http`.
(b) Decidir sobre o `npm audit`. (c) Confirmar se ler a instrução do piloto para adaptá-la
é compatível com a regra 8 do `CLAUDE.md`.

**Confirmações.** Nenhuma funcionalidade das AGT-002 a AGT-018 foi antecipada. Nenhum commit foi
realizado. A atividade não foi classificada nem declarada aprovada pelo agente.
